# **App Name**: StudyPilot AI

## Core Features:

- AI Tutor Chat: Ask questions and receive explanations on various topics using Google's Gemini models.
- Note Summarizer: Upload notes or text files to receive concise summaries powered by Google's Gemini models.
- Dynamic Flashcards: Automatically generate flashcards for any topic, powered by Google's Gemini models.
- Smart Quiz Engine: Create quizzes with multiple-choice and true/false questions using Google's Gemini models.
- Study History: Save user interactions, including questions, summaries, and generated content to Cloud Firestore.
- Secure Authentication: Secure user authentication via Firebase Authentication with email/password and Google Sign-In.
- Sleek, Responsive UI: A modern, dark-mode-first interface built with ShadCN UI and Tailwind CSS.

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) to convey trustworthiness and intelligence, nodding towards the academic context.
- Background color: Light gray (#F5F5F5), a very desaturated blue, for a clean and focused learning environment within a light color scheme.
- Accent color: A slightly lighter, but highly saturated blue-violet hue (#673AB7), used to create clear contrast and to draw attention to CTAs.
- Body and headline font: 'Inter', a grotesque-style sans-serif, providing a modern and neutral look suitable for both headlines and body text.
- Use minimalist and clear icons sourced from libraries like 'Lucide React' to represent different study tools and functionalities.
- Implement a clean and intuitive layout, focusing on easy navigation and content discoverability. Use a grid-based system to ensure consistency.
- Subtle animations and transitions to enhance user experience and provide feedback on interactions.
